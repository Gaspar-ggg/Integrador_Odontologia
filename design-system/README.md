## Propósito
Proveer una base visual y de componentes reutilizables, coherentes y accesibles para la interfaz web del sistema **La Muelita Cuyana** (Integrador Odontología).

## Estructura de Archivos
- `tokens.css`: Variables CSS de colores, tipografías, espaciados, bordes, sombras y soporte para movimiento reducido.
- `brand.md`: Lineamientos de marca, tono visual y pautas de logotipo.
- `brand.js`: Constante centralizada de nombre de marca (`La Muelita Cuyana`) y auto-binding DOM `[data-brand-name]`.
- `components.html`: Catálogo vivo de componentes representativos (botones, badges de turnos, inputs y tarjetas).
- `assets/logo.svg`: Isotipo y logotipo oficial de la clínica (muela estilizada con trazos cuyanos y sol).
- `previews/`: Capturas de referencia visual para desktop (`desktop-1440.png`) y mobile (`mobile-390.png`).
